# ICBO
Scripts and genotype data used in the "Efficient Optimization of Genotype Pairs for Intercropping using Genomic Prediction and Bayesian Optimization"

This repository contains materials related to the preprint:

Kinoshita, S. & Iwata, H. (2026). 
Efficient Optimization of Genotype Pairs for Intercropping using Genomic Prediction and Bayesian Optimization. 
bioRxiv. https://doi.org/

Please cite the preprint above if you use this repository.
